# Grilling

## Establish scope and facts
Identify the decision, intended outcome and requested depth. Planning stays planning
until implementation is authorized; existing authorization need not be requested again.
Read relevant materials for facts before asking the user. Mark evidence and unknowns;
use one agent unless delegation is authorized. Missing access is a gap, not a guessed fact.

## Work the decision frontier
Represent decisions and prerequisites. The frontier contains decisions whose prerequisites
are settled. Ask only from that frontier: normally one to three high-impact independent
questions, but adapt the round size to the user's preference and task. Small rounds can
increase total turns, so do not claim they inherently save tokens.

Use this compact round structure, adjusted to the question tool if available:

1. **Question / decision ID:** the choice to make.
2. **Prerequisite:** the settled fact/decision that makes it answerable now.
3. **Options and trade-off:** meaningful alternatives.
4. **Recommendation and reason:** a proposal, not assumed agreement.

Avoid wording designed to make agreement automatic. Wait for required decisions before
advancing dependent work. Continue independent investigation where useful. A question
whose answer depends on another open question belongs in a later round.

## Keep a decision ledger
Maintain settled decisions with their source, assumptions, current frontier, explicitly
deferred branches and blockers with their dependency/impact. Keep it in the response
unless the task authorizes a durable artifact. After each answer recompute the frontier;
carry deferred items forward rather than silently dropping them. Challenge contradictions
respectfully and distinguish existing behavior from intended behavior. Do not ask the
user to repeat facts already established by available materials.

## Finish at the agreed boundary
Stop when the requested scope is resolved or the user asks to stop. Return decisions,
remaining assumptions/blockers, deferred branches, non-goals and the next concrete step.
Do not promise to resolve every possible branch. Recommendations and elapsed time are
not approval; a missing required answer remains a blocker, not permission to guess.
